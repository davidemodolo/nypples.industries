Huawei Ascend 910C: Each node features the Da Vinci architecture with native FP16 performance of approximately 320 TFLOPS. Paired with 64 GB HBM2E memory per GPU, delivering 1.6 TB/s memory bandwidth. The cluster is organized into four 5-node groups connected via 800 Gbps RoCE v2 networking, providing near-InfiniBand latency for tensor parallelism across nodes.
