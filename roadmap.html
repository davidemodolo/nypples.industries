Product Roadmap

Our path from first deployment to full-spectrum European AI infrastructure provider.

  • 20x Ascend 910C nodes deployed at Equinix FR5 Frankfurt
  • DeepSeek V4 Pro & Flash, GLM-5.2, Kimi K2.7 Code live
  • Batch processing launched: summarization, classification, NER, embeddings
  • BGE-M3, Stella-400M, GTE-Qwen2 embedding endpoints
  • OpenAI-compatible REST/gRPC API with API key management
  • GDPR-compliant data processing framework v1.0
Q4 2026

Phase 1.5: Expansion & Kimi K3

  • Kimi K3 launch — day-one support. Moonshot AI's next flagship model deployed on release day
  • Real-time tier expands from 500 to 1,000 concurrent slots
  • Qwen3.7-Max added to model catalog with Premium availability
  • Batch RAG pipeline beta: ingest → chunk → embed → retrieve → generate
  • Customer dashboard launched: usage analytics, spend tracking, token forecasting
  • GPU utilization reaches 25-30%, approaching break-even revenue
Q1 2027

Phase 2: Custom Models & Hardware Expansion

  • Custom LoRA training service: Bring your dataset, receive a fine-tuned LoRA adapter hosted on our infrastructure. Isolated per-tenant, billed per training hour + inference
  • Nypples EU Legal Anonymizer (LoRA): First-party fine-tuned adapter for automatic PII redaction in legal/financial documents. GDPR Article 17 response helper. Built on Qwen3.7-Plus base
  • Nypples Neural Machine Translation (LoRA): Machine translation fine-tuned on EU languages (EN, DE, FR, IT, ES, NL, PL, SV, DA, FI, PT, EL, CS, HU, RO, SK, BG, LT, LV, SL, ET, MT, GA, HR). Built on Gemma 4 31B base
  • Phase 2 GPU expansion: +15 Ascend 920 nodes, upgrading total compute to ~11 PFLOPS. +€600K investment (bridge round or revenue reinvestment)
  • Networking upgrade to 1600 Gbps aggregate interconnect
Q2 2027

Phase 2.5: Enterprise Features

  • On-premise deployment option: "Nypples-in-a-box" — pre-configured Ascend rack + software stack for enterprises running in their own datacenters. One-time license + annual support
  • RAG pipeline as a service: Fully managed retrieval-augmented generation. Upload documents, we handle chunking, embedding, indexing, retrieval, and answer generation via flagship models
  • SOC 2 Type II audit process initiated
  • EU AI Act readiness assessment published. High-risk classification guidance for customers
  • Customer success team hired (2 FTE)
Q3 2027

Phase 3: Scale-Up

  • Revenue target: €180,000/month recurring. GPU utilization >60%
  • Series A fundraise: €3-5M for multi-region EU expansion
  • Second datacenter: Amsterdam or Madrid, adding 25-30 Ascend 920 nodes for geographic redundancy and lower latency to Southern/Western Europe
  • Multi-modal models: vision-capable open-weight models deployed as they become available
  • Formal partnership with Z.ai (GLM) and Moonshot AI (Kimi) for optimized Ascend deployment
  • Published infrastructure reference architecture for Ascend-based AI inference (open source)
