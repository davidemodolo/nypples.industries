01 / API

OpenAI-compatible API.

Drop-in replacement for the OpenAI Python SDK. Swap api.nypples.industries for api.openai.com and your code runs unchanged — on European soil.

Base URL
https://api.nypples.industries/v1
02 / Auth

Authentication.

All API requests require a valid API key. Generate keys from the Nypples dashboard.

POST — Bearer token, identical to OpenAI's auth scheme.

Include your API key in the Authorization header. All API keys are scoped to your organization and rate-limited per tier.

curl https://api.nypples.industries/v1/models \
  -H "Authorization: Bearer nyp_sk_xxxxxxxxxxxxxxxxxxxxxxxx"
API key format: Keys use the prefix nyp_sk_ followed by 32 hex characters. You can create, rotate, and revoke keys from the Dashboard → API Keys section.
03 / Chat

Chat completions.

OpenAI-compatible /v1/chat/completions endpoint. Supports streaming, system prompts, tool calling, and structured output.

POST /v1/chat/completions 
curl https://api.nypples.industries/v1/chat/completions \
  -H "Authorization: Bearer $NYPPIES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Explain GPU tensor parallelism in one sentence."}
    ],
    "temperature": 0.7,
    "max_tokens": 200,
    "stream": false
  }'
Python SDK 
from openai import OpenAI

client = OpenAI(
    api_key="nyp_sk_xxxxxxxxxxxxxxxxxxxxxxxx",
    base_url="https://api.nypples.industries/v1"
)

response = client.chat.completions.create(
    model="deepseek-v4-pro",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the capital of Italy?"}
    ],
    temperature=0.7,
    max_tokens=200
)

print(response.choices[0].message.content)
POST /v1/chat/completions — Streaming 
from openai import OpenAI

client = OpenAI(
    api_key="nyp_sk_xxxxxxxxxxxxxxxxxxxxxxxx",
    base_url="https://api.nypples.industries/v1"
)

stream = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[
        {"role": "user", "content": "Write a haiku about GPUs."}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")

Supported parameters

ParameterTypeDefaultDescription
modelstring—Model ID. See Model Catalog for supported values.
messagesarray—List of messages in OpenAI format.
temperaturefloat0.7Sampling temperature, 0.0–2.0.
max_tokensint4096Maximum tokens in the response. Model-dependent max.
streamboolfalseEnable token-by-token streaming.
top_pfloat1.0Nucleus sampling.
frequency_penaltyfloat0.0Penalty based on existing token frequency.
presence_penaltyfloat0.0Penalty based on token presence.
stopstring|arraynullStop sequence(s).
04 / Embeddings

Embeddings API.

Generate vector embeddings for text. Compatible with OpenAI's /v1/embeddings format.

POST /v1/embeddings 
curl https://api.nypples.industries/v1/embeddings \
  -H "Authorization: Bearer $NYPPIES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "bge-m3",
    "input": "Your text to embed goes here."
  }'
Python SDK 
from openai import OpenAI

client = OpenAI(
    api_key="nyp_sk_xxxxxxxxxxxxxxxxxxxxxxxx",
    base_url="https://api.nypples.industries/v1"
)

response = client.embeddings.create(
    model="bge-m3",
    input="European sovereign AI infrastructure"
)

print(response.data[0].embedding[:5])  # [0.023, -0.041, 0.015, ...]

curl https://api.nypples.industries/v1/models \

06 / Limits

Rate limits & errors.

Rate limits

Per-tier concurrency

Premium real-time: 500 concurrent slots. Standard real-time: 250 concurrent slots. Batch: unlimited queued volume. Embeddings: 2,000 requests/min. Exceeding limits returns HTTP 429.

Error codes

Standard HTTP semantics

400 Invalid request · 401 Invalid API key · 429 Rate limit exceeded · 500 Internal server error. All errors return {"error": {"message": "...", "type": "..."}} matching OpenAI's format.
